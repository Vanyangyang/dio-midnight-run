# DIO · Midnight Run

用手绘 SVG 还原 DIO 的开罗深夜人行道狂飙场面。非官方《JOJO 的奇妙冒险》同人动画。

**[在线播放](https://vanyangyang.github.io/dio-midnight-run/)**

18 秒循环，包含漫画特写、夜间街景、越过路缘、烟尘和速度线。支持暂停、进度拖动、分镜跳转、倍速、全屏与可选合成引擎音效。

## 本地播放

下载后直接用浏览器打开 `index.html`。所有 SVG、CSS 和 JavaScript 都在同一文件内，无需安装依赖或联网。

- `Space`：播放 / 暂停
- `←` / `→`：后退 / 前进 1 秒
- `R`：从头重播
- `F`：进入 / 退出全屏

音效默认关闭；启用系统“减少动态效果”时，动画默认暂停。

## 部署

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留静态文件直接发布方式。
